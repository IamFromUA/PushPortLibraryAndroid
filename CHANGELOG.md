# Изменения SDK

## 0.0.1 — кандидат первого публичного выпуска, 2026-09-13

- Добавлена передача Android ID как необязательного поля `androidId`. Недоступные значения не мешают регистрации; прежние установки, их ID и публичный API сохранены.
- Номер первого публичного выпуска установлен в `0.0.1`. Предыдущие номера ниже относятся к локальным сборкам, которые не публиковались в Maven Central.
- Все возможности и подготовка библиотеки из этих сборок входят в `0.0.1`; публичный API и формат сохранённых данных не изменены.
- Версия обновлена в Maven-артефактах, метаданных SDK, документации и зависимостях тестовых приложений.

## История локальных сборок до выбора номера публичного выпуска

## 0.3.0 — локальный кандидат, 2026-09-12

- Изображение по публичному HTTPS URL: текст показывается сразу, WorkManager отдельно загружает изображение и обновляет существующее уведомление без повторного звука.
- HTTPS-ссылка открывается по нажатию; без ссылки открывается приложение. Учёт открытий сохраняется.
- Загрузка ограничена временем, размером и количеством пикселей; приватные DNS-адреса, переадресации и URL с паролями отклоняются. Неудачная загрузка оставляет текстовое уведомление.
- OkHttp 5.3.2 подключается транзитивно. Новая Android-точка входа NotificationImageWorker добавлена в правила R8 и ABI baseline; существующий публичный API и сохранённая установка совместимы с 0.2.0.
- Добавлены проверки декодирования, HTTPS/DNS и обновления уведомлений.

Подготовка первого публичного выпуска:

- Сборка и проверка SDK выполняются через Gradle и GitHub Actions; подключение в приложения — обычной Maven-зависимостью с автоматической загрузкой зависимостей.

- 2026-09-13: подготовлен самостоятельный репозиторий PushPortLibraryAndroid: Gradle Wrapper с проверкой SHA-256, Git ignore, SCM-метаданные, проверка артефактов и Kotlin/Java consumer с R8, workflow проверки GitHub Actions.

- 2026-09-13: выбрана Apache License 2.0, правообладатель и издатель — Oleh Yurkov. Добавлены LICENSE, NOTICE, данные издателя в POM и включение лицензии в AAR, sources и Dokka JAR.

- Добавлены проверка Kotlin/JVM API из готового release AAR и сохраняемый baseline. Проверка включает имена Android-компонентов и подключена к `check`.
- Добавлены ArchUnit-проверки границ ядра, моделей и адаптеров, а также отсутствия циклов пакетов.
- Добавлены Dokka, подробные KDoc-контракты и JAR справочника API. README разделён на краткое подключение и руководства по API, архитектуре, данным, совместимости, тестированию и выпуску.
- Временная ошибка или таймаут FCM теперь приводит к ограниченному повтору задачи после регистрации метаданных. Неверная конфигурация обрабатывается отдельно.
- Некорректный ответ конфигурации больше не принимается за явное отключение Firebase.
- Строковое представление `PushPortStatus` не раскрывает FCM-токен. Список локалей статуса копируется из состояния.
- Ошибки URL/локали приводятся к `IllegalArgumentException`; неверные порты отклоняются до изменения состояния. Добавлен двухаргументный Java-конструктор конфигурации без удаления существующих сигнатур.
- Отслеживание открытий выделено в отдельный внутренний компонент. Имена Android-компонентов, ключи протокола и формат хранения PushPort сохранены.
- Режим `libraryOnly` исключает модули бэка. Gradle запускает полные проверки SDK и генерацию документации; архивы имеют воспроизводимый порядок и временные метки.

Это локальные изменения до публикации. Пространство имён dev.pushport подтверждено, лицензия выбрана. Репозиторий SDK и workflow подготовлены локально; первый push, подпись и учётные данные публикации ещё предстоят; версия в Central не выпущена.

## 0.2.0 — локальная версия, 2026-09-11

- Продукт и SDK переименованы в PushPort: `dev.pushport:android-sdk`, пакет `dev.pushport.sdk`.
- Изменены публичные классы, Android-компоненты, имена работы, канала, ресурсов и файла состояния. Это несовместимое переименование предварительной версии; автоматического переноса старого файла нет.
- Стандартный адрес сервера — `https://pushport.dev`; локальная сборка может задавать тестовый HTTPS endpoint.
- Проверены сборка приложения из Maven AAR, release/R8 и получение настоящего пуша новым Firebase-проектом.

## 0.1.1 — 2026-09-07

- Разделены публичный API, бизнес-логика, хранилище, HTTP, Firebase и Android-компоненты. Зависимости внедряются через конструкторы.
- Между слоями используются типизированные модели; JSON локализован в адаптерах.
- Сохранены публичные JVM-сигнатуры, имена Android-точек входа и данные установки версии 0.1.0. Добавлен номер схемы локального состояния.
- Отмена родительской coroutine больше не принимается за собственный таймаут получения токена.
- При удалении Firebase-конфигурации с сервера очищаются устаревшие сохранённые настройки и токен.
- Добавлены KDoc, explicit API mode, ktlint и `.editorconfig`; тесты разделены на сценарии ядра и проверки адаптеров.
- Пройдены 22 теста, Android Lint, сборки debug/release и реальная проверка обновления с доставкой пуша на Android 17.

## 0.1.0

Первый локальный SDK: регистрация установки и токена, автоматическая синхронизация языка/локали, получение и открытие FCM-пушей, Maven AAR с транзитивными зависимостями.
